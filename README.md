# 🚀 Slack API를 사용한 회의실 예약 시스템 구축

➡️ 계열사 간 회의실 예약 시 발생하던 불편을 줄이고, 예약 알림 기능과 모바일 확인 편의성을 높이기 위해 적용되었습니다.

## 프로젝트 전체 흐름
- 이 프로젝트는 회사별로 분리된 Slack 워크스페이스와 Docker 컨테이너 환경에서 동작하며, 사용자의 회의실 예약 요청을 받아 예약 가능 여부를 확인한 뒤 DB에 저장하는 구조입니다.

  ### 1. 회사별 환경 분리

  - 회사마다 별도의 Slack 워크스페이스 또는 운영 환경을 사용합니다.
  - 각 회사는 독립된 Docker 컨테이너에서 실행됩니다.
  - 회사별로 환경 변수, 회의실 목록, 층 정보, 인증 정보, DB 설정을 분리해서 관리합니다.

  ### 2. 사용자 요청 수신

  - 사용자는 Slack에서 회의실 예약 기능을 실행합니다.
  - 앱은 Slack Bolt를 통해 사용자 입력을 받습니다.
  - 이 과정에서 회사, 층, 회의실, 날짜, 시작 시간, 종료 시간 등의 예약 정보를 수집합니다.

  ### 3. 예약 시간 가공    
                                                                                                                                                                                          
  - 입력된 시작 시간과 종료 시간을 기준으로 예약 시간을 30분 단위 슬롯으로 나눕니다.                                                                                                                                           
  - 예를 들어 10:00~11:00 예약이면 `10:00`, `10:30` 두 개 슬롯으로 변환됩니다.                                                                                                                                                 
  - 이렇게 나눈 슬롯 단위로 예약 가능 여부를 확인합니다.                                                                                                                                                                       
                                                                                                                                                                                                                               
  ### 4.중복 예약 확인
                                                                                                                                                                                             
  - DB에서 같은 회사, 같은 날짜, 같은 층, 같은 회의실, 같은 시간대에 이미 예약이 있는지
  조회합니다.

  - 하나라도 겹치는 슬롯이 있으면 중복 예약으로 판단합니다.                                                                                                                                                                    

  ### 5. 예약 저장

  - 중복이 없으면 예약 정보를 DB에 저장합니다.
  - 예약 시간은 30분 단위 슬롯별로 저장됩니다.
  - 사용자는 특정 날짜와 회의실 기준으로 예약 현황을 조회할 수 있습니다.
  - 시스템은 DB에서 이미 예약된 시간 슬롯을 불러와 예약 가능 여부 판단에 활용합니다.
